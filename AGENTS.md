# Agent instructions (ElderCare)

## Git commits

- **Do not** commit as `Cursor Agent` / `cursoragent@cursor.com`.
- **Do not** add `Co-authored-by` trailers or other metadata that associates Cursor/AI with commits.
- Use the **human developer's** local git identity (`git config user.name` / `user.email` on their machine), or ask which author to use before committing.
- Keep commit messages factual and neutral — describe the change only, without mentioning AI/agents.
